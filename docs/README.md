# Документация ZealousMindedPeopleGeo

Библиотека состоит из двух частей:

- **C# / Blazor.** Razor-компоненты, сервисы и модели. С ними работает приложение.
- **JavaScript в браузере.** Глобус на Three.js, 2D-карта на Canvas, PWA. Скрипты лежат в
  библиотеке, и компоненты загружают их сами.

Приложению нужен только .NET SDK. Node.js нужен лишь тому, кто меняет библиотеку и запускает
её тесты JavaScript.
